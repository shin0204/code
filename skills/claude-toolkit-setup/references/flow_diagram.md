## 플로우 단계별 상세

### 1️⃣ 한도를 늘린다 (토큰/성능 최적화)

```
OmniRoute + Headroom
     │
     ├─ OmniRoute
     │   ├─ 작업 복잡도 분석
     │   ├─ 필요 토큰 예상
     │   ├─ 모델별 성능/비용 계산
     │   └─ 최적 모델 선택
     │       ├─ 복잡 작업 → claude-opus-5
     │       ├─ 균형 작업 → claude-sonnet-5
     │       └─ 간단 작업 → claude-haiku
     │
     └─ Headroom
         ├─ 이전 컨텍스트 분석
         ├─ 압축 알고리즘 선택
         ├─ 토큰 30-40% 절감
         └─ 비용 감소
```

**결과**: 같은 품질, 더 빠르고 저렴

---

### 2️⃣ 기억을 잇는다 (메모리 지속성)

```
Claude Mem
     │
     ├─ 메모리 수집 (각 세션)
     │   ├─ User Profile: 선호도, 스타일, 목표
     │   ├─ Project Context: 구조, 결정사항, 진행상황
     │   ├─ Patterns: 반복되는 작업, 습관
     │   └─ Feedback: 성공/실패 경험
     │
     ├─ 자동 인덱싱
     │   ├─ 시간 기반: 최근 세션 우선
     │   ├─ 관련성 기반: 유사 작업 연결
     │   └─ 신뢰도 기반: 증명된 정보 우선
     │
     └─ SessionStart에 자동 로드
         ├─ 현재 프로젝트 메모리
         ├─ 유사 작업 메모리
         ├─ 사용자 선호도
         └─ 지난 실패 교훈
```

**결과**: 세션이 끝나도 기억, 더 나은 컨텍스트

---

### 3️⃣ 환경을 잡는다 (설정 최적화)

```
Claude Code Setup
     │
     ├─ 프로젝트 감지
     │   ├─ 타입 인식 (web/backend/data/ml/etc)
     │   ├─ 기술 스택 식별 (언어, FW, DB)
     │   ├─ 팀 규모 감지 (1명/팀/조직)
     │   └─ 기존 설정 분석
     │
     ├─ 최적 설정 추천
     │   ├─ 권한 규칙 (strict/permissive)
     │   ├─ 도구 조합 (추천 플러그인/스킬)
     │   ├─ 자동화 규칙 (훅, 대기열)
     │   └─ 팀 표준 적용
     │
     └─ 설정 자동 적용
         ├─ CLAUDE.md 생성/업데이트
         ├─ settings.json 병합
         ├─ .claude/settings.local.json 개인화
         └─ 팀 가이드라인 다운로드
```

**결과**: 내 프로젝트에 최적 환경

---

### 4️⃣ 스스로 나아진다 (자가 개선)

```
Task Observer + Graphify
     │
     ├─ Task Observer (패턴 분석)
     │   ├─ 세션별 활동 기록
     │   │   ├─ 사용 도구
     │   │   ├─ 작업 시간
     │   │   ├─ 효율성 메트릭
     │   │   └─ 성공/실패 결과
     │   │
     │   ├─ 패턴 감지
     │   │   ├─ 반복되는 작업 (스킬화 후보)
     │   │   ├─ 효율성 트렌드
     │   │   ├─ 실수 패턴
     │   │   └─ 학습 곡선
     │   │
     │   └─ 개선 제안
     │       ├─ "이 작업 스킬로 만들까?"
     │       ├─ "이 도구 조합이 자주 쓰이네"
     │       ├─ "여기서 자주 실수하네"
     │       └─ "효율이 30% 개선됐어!"
     │
     └─ Graphify (지식 구조화)
         ├─ 개념 노드 생성
         │   ├─ 핵심 개념 추출
         │   ├─ 새로운 아이디어
         │   └─ 학습 목표
         │
         ├─ 연결 관계 구성
         │   ├─ 개념 간 관계
         │   ├─ 의존성 분석
         │   └─ 위계 구조
         │
         └─ 시각화 및 공유
             ├─ 개념 그래프 생성
             ├─ 학습 경로 표시
             └─ 외부 자료 링크
```

**결과**: 내 방식을 보고 자동으로 개선

## 통합 예시: 실제 작업 흐름

### 상황: "이번 주 데이터 분석 리포트 작성"

```
┌─ SessionStart ─────────────────────────────────────────────────┐
│  ✅ Claude Mem: "지난주 분석 결과" 로드                        │
│  ✅ Code Setup: "데이터 분석 프로젝트" 설정                    │
│  ✅ OmniRoute: "복잡 분석이니 Opus 추천" 결정                  │
│  ✅ Headroom: "지난주 분석 컨텍스트 30% 압축"                 │
└────────────────────────────────────────────────────────────────┘
                            ↓
┌─ 실제 작업 (유저) ─────────────────────────────────────────────┐
│  1. 데이터 로드 및 정제                                        │
│     - Ponytail: 간단하게, 필수만                              │
│     - OmniRoute: Opus 사용 (복잡 분석)                        │
│                                                                │
│  2. 분석 및 시각화                                            │
│     - Headroom: 컨텍스트 압축 (토큰 20% 절감)               │
│     - Task Observer: "데이터 분석 패턴" 기록                 │
│                                                                │
│  3. 리포트 작성                                               │
│     - 이전 템플릿 사용 (Claude Mem에서)                      │
│     - 스타일 자동 적용 (Code Setup)                          │
└────────────────────────────────────────────────────────────────┘
                            ↓
┌─ SessionEnd ───────────────────────────────────────────────────┐
│  ✅ Task Observer: "이 작업 90분, 효율 85%"                   │
│  ✅ Task Observer: "분석 → 시각화 → 리포트 3단계 반복"        │
│  ✅ Task Observer: "이걸 스킬로 만들까?"                      │
│                                                                │
│  ✅ Graphify: "데이터분석 → EDA → Viz → Report" 그래프       │
│  ✅ Graphify: "지난주 분석과 연결"                            │
│                                                                │
│  ✅ Claude Mem: "주간 데이터 분석 리포트" 저장                │
│  ✅ Claude Mem: "Opus 사용, Headroom 압축" 패턴 기록         │
│  ✅ Claude Mem: "90분 소요, 효율 85%" 메트릭 저장            │
│                                                                │
│  ✅ 다음 주 추천:                                             │
│    - Opus 모델 미리 선택                                      │
│    - "데이터 분석" 메모리 프리로드                            │
│    - "분석 리포트 작성" 스킬 생성 제안                        │
│    - 지난주 지식 그래프 로드                                  │
└────────────────────────────────────────────────────────────────┘
```

### 결과
- **시간**: 90분 → 다음주 60분 (33% 단축)
- **비용**: 토큰 30% 절감 (Headroom)
- **품질**: 이전 경험 100% 반영
- **자동화**: 다음주 스킬로 추가 가능

## 문제 발생 시 복구 플로우

```
문제 감지 (Task Observer)
        ↓
    에러 분석
        ↓
    ├─ OmniRoute 문제 → 모델 전환
    ├─ Headroom 문제 → 컨텍스트 재구성
    ├─ Claude Mem 문제 → 수동 메모리 로드
    └─ 기타 문제 → 설정 재검증
        ↓
    자동 복구 시도
        ↓
    성공? ✅ → 문제 해결, 원인 기록
    실패? ❌ → 사용자에게 보고, 수동 개입 요청
```
